# assets/

Drop your LinkedIn profile photo here as **`profile.jpg`** (square, at least
400×400px works best — it gets cropped to a circle).

If `assets/profile.jpg` is missing, every page automatically falls back to a
"MC" initials badge, so the site still works without it — just less
personal.

Nothing else needs to go in this folder unless you add extra images (e.g.
per-project screenshots) — reference them from `js/projects-data.js`.

Do **not** put anything private here (resumes/CVs with personal data, ID
documents, unpublished work, API keys, etc.) — this repository is public.
